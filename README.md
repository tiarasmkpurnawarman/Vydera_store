# Vydera Store — Game Top Up

Website front-end responsif untuk pilihan top up game. Desain menggunakan Bootstrap 5, dengan aksen neon, navigasi responsif, kartu layanan, pemilihan game dan paket, ringkasan pesanan, kode promo, modal konfirmasi, FAQ, serta formulir kontak.

## Isi folder
- `index.html` — struktur dan komponen halaman.
- `style.css` — desain visual dan penyesuaian desktop/mobile.
- `app.js` — logika pilihan game, paket, kalkulasi harga, promo, dan interaksi.
- `assets/images/logo.svg` — logo vektor Vydera Store (disimpan di folder `assets/images`).
- `URL_GITHUB_PAGES.txt` — tempat mencatat alamat website setelah dipublikasikan.

## Game yang tersedia di pemilih paket
- Mobile Legends: Bang Bang
- Free Fire
- Honor of Kings
- PUBG Mobile
- Valorant
- Genshin Impact

## Cara menjalankan
1. Ekstrak ZIP ke folder komputer.
2. Buka folder tersebut di Visual Studio Code.
3. Buka `index.html` di browser, atau gunakan ekstensi Live Server.
4. Koneksi internet diperlukan untuk memuat Bootstrap, Bootstrap Icons, dan Google Fonts dari CDN.

## Melihat tampilan mobile
Di Chrome desktop, buka website lalu tekan `F12` dan klik ikon perangkat (Toggle device toolbar). Pilih ukuran ponsel untuk memeriksa layout responsif. Untuk membuka dari HP sungguhan, publikasikan website melalui GitHub Pages lalu buka URL Pages dari browser HP.

## Catatan layanan
Harga dan paket di halaman ini adalah contoh tampilan, bukan daftar harga resmi atau jaminan ketersediaan. Checkout, pembayaran, dan pengiriman item belum terhubung ke layanan backend. Jangan gunakan untuk menerima pembayaran nyata sebelum integrasi dan harga diverifikasi.
